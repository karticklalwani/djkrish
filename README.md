# DJ KRISHLWN

Web responsive estática con fotografías originales del usuario. Contacto exclusivamente por Instagram: https://www.instagram.com/krishlwn.

Incluye Home, Sobre mí, Galería con ampliación, Música, Agenda y Contacto. Sin biografía inventada, enlaces musicales ni fechas ficticias. La portada usa una foto real de la pista en blanco y negro; la galería conserva las cuatro imágenes en color.

La carpeta publicable es `dist`, sin instalación ni compilación. Para revisión local abre `dist/index.html` o sirve `dist` con un servidor estático. El contenido verificado se mantiene en `dist/content.js`.

El alojamiento está creado y configurado como privado, pero la publicación está pendiente: el entorno bloqueó la sincronización. La configuración del alojamiento se encuentra en `.openai/hosting.json`.
